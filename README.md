# alphabet-game

小学2〜3年生向けの、アルファベット学習Webアプリです。

## ねらい

- 大文字モード / 小文字モードを分ける
- 文字の読み方をカタカナと音声で確認する
- 「選ぶ」と「書く」の両方を行う
- 子ども向け画面では漢字を使わない
- 全10ステージ + 最終チャレンジを約40分で一周できる量にする
- 進捗は端末の `localStorage` に保存する

## 学習の流れ

各ステージは5〜6文字です。

1. カタカナの読み方をタップして音声確認
2. 読み方を聞いて4択から文字を選択
3. 薄いお手本を指やマウスでなぞる
4. ステージクリアで★を獲得
5. 大文字・小文字の全ステージ完了後に最終チャレンジ

Z の読みは「ズィー」にしています。

## 動かし方

ビルドは不要です。`index.html` を静的ホスティングすれば動きます。

ローカル確認例:

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。
